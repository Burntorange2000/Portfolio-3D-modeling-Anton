ОПИСАНИЕ ПРОЕКТА:
----------------
Сайт-портфолио 3D-художника "portfolio".
Состоит из трёх страниц:
1. Главная (index.html) - портфолио с работами, сетка проектов
2. Обо мне (about.html) - информационная страница о художнике
3. Контакты (contact.html) - форма обратной связи и контактная информация

ИСПОЛЬЗОВАННЫЕ ТЕХНОЛОГИИ:
--------------------------
- HTML
- CSS3 (Flexbox, Grid)
- Адаптивный дизайн

ОСОБЕННОСТИ ДИЗАЙНА:
--------------------
- Тёмная тема с неоново-фиолетовыми акцентами
- Стеклянный эффект (glassmorphism) с backdrop-filter
- Градиентные элементы (заголовки, кнопки, фон)
- Плавные анимации карточек при наведении (transform, box-shadow)
- Адаптивная сетка Grid для портфолио
- Эффект свечения текста и границ

СТРУКТУРА ПРОЕКТА:
------------------
index.html       - Главная страница (портфолио)
about.html          - Информационная страница (о художнике)
contact.html        - Контакты и форма обратной связи
style.css           - Стили (Flex, Grid, анимации, адаптив)


ОСОБЕННОСТИ РЕАЛИЗАЦИИ:
-----------------------
1. Главная страница:
   - Grid-сетка с auto-fill для резиновой вёрстки
   - Карточки с иконками-эмодзи в качестве превью
   - Крупные проекты занимают 2 колонки (item-large)

2. Страница "Обо мне":
   - Двухколоночный Grid (фото + текст)
   - Сетка статистики 
   - Сетка инструментов (Blender, ZBrush, Maya и др.)

3. Страница "Контакты":
   - Двухколоночный Grid (контактная информация + форма)
   - Форма обратной связи с полями: имя, email, тип проекта, сообщение
   - Список услуг

4. Адаптивность:
   - На мобильных устройствах сетки превращаются в одну колонку
   - Навигация становится вертикальной
   - Шрифты уменьшаются
